# Asphalt Calculator

Free asphalt calculator for driveway, parking lot, and small paving project estimates.

**Live site:** https://www.asphaltprice.com

## What it does

- Estimates asphalt tonnage
- Estimates material cost
- Supports region-based pricing
- Works on desktop and mobile

## Tech stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Notes

This project is focused on quick, practical cost estimates for homeowners, contractors, and property managers.
